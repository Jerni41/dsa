## Динамическое программирование
### Задача о рюкзаке с возможностью дробить предметы (Fractional Knapsack)

```python
def fractional_knapsack(items, capacity):
    items.sort(key=lambda x: x.price / x.weight, reverse=True)
    total_value = 0.0
    for item in items:
        if capacity >= item.weight:
            total_value += item.price
            capacity -= item.weight
        else:
            total_value += item.price * (capacity / item.weight)
            break
    return total_value

class Item:
    def __init__(self, price, weight):
        self.price = price
        self.weight = weight

items = [Item(60, 15), Item(90, 30), Item(100, 50)]
capacity = 80
print(f"Максимальная стоимость (дробный рюкзак): {fractional_knapsack(items, capacity)}")
```

Что за алгоритм: Жадный алгоритм для задачи о рюкзаке с дроблением. Сортируем предметы по "выгодности" (цена/вес) и берем самые выгодные, пока есть место. Если предмет не помещается целиком - берем его часть.

Пример из жизни: Вы пришли на рынок купить фрукты. У вас есть 80 рублей. Продавец продает яблоки (60 руб/кг), бананы (90 руб/3 кг) и апельсины (100 руб/5 кг). Вы хотите максимально потратить деньги, но фрукты можно купить в любом количестве (хоть полкило). Жадный алгоритм подскажет, что сначала нужно купить самые дорогие за кг (бананы - 30 руб/кг), потом яблоки, потом апельсины.

### Задача о покрытии отрезками (Interval Covering Problem)

```python
def interval_covering(segments, target_start, target_end):
    segments.sort(key=lambda x: x[1])
    result = []
    current_pos = target_start
    i = 0
    while current_pos < target_end:
        best_end = current_pos
        while i < len(segments) and segments[i][0] <= current_pos:
            best_end = max(best_end, segments[i][1])
            i += 1
        if best_end == current_pos:
            return []
        result.append((current_pos, best_end))
        current_pos = best_end
    return result

segments = [(1, 4), (2, 5), (3, 6), (5, 7), (6, 8)]
target = (1, 8)
print(f"Минимальное покрытие: {interval_covering(segments, *target)}")
```

Что за алгоритм: Жадный алгоритм покрытия отрезка. Сортируем отрезки по правому концу, затем на каждом шаге выбираем отрезок, который начинается не позже текущей точки и уходит максимально вправо.

Пример из жизни: Вы планируете ремонт квартиры с 1 по 8 этаж. У вас есть бригады, каждая работает на определенном диапазоне этажей: 1-4, 2-5, 3-6, 5-7, 6-8. Нужно нанять минимальное количество бригад, чтобы покрыть все этажи с 1 по 8. Алгоритм подскажет: берем бригаду 1-4 (самую левую), потом ищем бригаду, которая начинается на этаже ≤4 и заходит дальше всех (это 3-6), затем 6-8.

### Задача о нахождении наименьшего пути (Floyd–Warshall)

```python
def floyd_warshall(graph):
    n = len(graph)
    dist = [[float('inf')] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
        for j, w in graph[i]:
            dist[i][j] = w

    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    return dist

graph = [
    [(1, 3), (2, 5)],
    [(2, 1)],
    []
]
print("Матрица кратчайших путей:")
for row in floyd_warshall(graph):
    print(row)
```

Что за алгоритм: Алгоритм Флойда-Уоршелла - классический алгоритм для нахождения кратчайших путей между всеми парами вершин во взвешенном графе. Использует динамическое программирование: на каждой итерации пытается улучшить путь, используя новую промежуточную вершину.

Пример из жизни: Карта метро. Вам нужно знать кратчайшее расстояние между ЛЮБЫМИ двумя станциями. Алгоритм Флойда-Уоршелла построит таблицу, где на пересечении строки "Киевская" и столбца "ВДНХ" будет минимальное время в пути с учетом всех пересадок.

### Задача о размене монет (Coin Change, DP-версия)

```python
def coin_change(coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for coin in coins:
        for i in range(coin, amount + 1):
            dp[i] = min(dp[i], dp[i - coin] + 1)
    return dp[amount] if dp[amount] != float('inf') else -1

coins = [1, 5, 11]
amount = 15
print(f"Минимальное количество монет для суммы {amount}: {coin_change(coins, amount)}")
```

Что за алгоритм: Динамическое программирование для задачи о размене монет. Строим решение снизу вверх: для каждой суммы от 1 до amount вычисляем минимальное количество монет, используя уже вычисленные значения для меньших сумм.

Пример из жизни: У кассира есть монеты 1, 5 и 11 рублей. Клиент просит разменять 15 рублей. Кассиру нужно дать минимальное количество монет. Жадный алгоритм (взять самую большую монету) даст 11+1+1+1+1 = 5 монет. ДП подскажет, что 5+5+5 = 3 монеты - это оптимальнее!

### Генерация разбиений множества (комбинаторный алгоритм)

```python
def set_partitions(elements):
    result = []

    def backtrack(idx, current_partition):
        if idx == len(elements):
            result.append([list(subset) for subset in current_partition])
            return
        for i in range(len(current_partition)):
            current_partition[i].append(elements[idx])
            backtrack(idx + 1, current_partition)
            current_partition[i].pop()
        current_partition.append([elements[idx]])
        backtrack(idx + 1, current_partition)
        current_partition.pop()

    backtrack(0, [])
    return result

print("Разбиения множества [1, 2, 3]:")
for part in set_partitions([1, 2, 3]):
    print(part)
```

Что за алгоритм: Комбинаторный алгоритм с использованием возврата (backtracking) для генерации всех разбиений множества. Каждый элемент либо добавляется в существующий блок, либо создает новый блок.

Пример из жизни: У вас есть 3 разных подарка (1,2,3) для друзей, но вы не знаете, как их сгруппировать. Нужно рассмотреть все способы разбить подарки на группы (возможно, одному другу несколько подарков). Алгоритм перечислит все варианты: [1],[2],[3]; [1,2],[3]; [1,3],[2]; [2,3],[1]; [1,2,3].

### Оптимизация многомерной функции (генетический алгоритм)

```python
import random

def fitness_function(individual):
    x, y = individual
    return -x**2 - y**2 + 10

def initialize_population(size, bounds=(-10, 10)):
    return [(random.uniform(*bounds), random.uniform(*bounds)) for _ in range(size)]

def tournament_selection(population, tournament_size=5):
    tournament = random.sample(population, tournament_size)
    return max(tournament, key=fitness_function)

def crossover(p1, p2):
    return ((p1[0] + p2[0]) / 2, (p1[1] + p2[1]) / 2)

def mutate(individual, mutation_rate=0.1):
    if random.random() < mutation_rate:
        return (individual[0] + random.gauss(0, 0.5), individual[1] + random.gauss(0, 0.5))
    return individual

def genetic_algorithm(generations=100, pop_size=50):
    population = initialize_population(pop_size)
    for _ in range(generations):
        new_pop = []
        for _ in range(pop_size):
            p1 = tournament_selection(population)
            p2 = tournament_selection(population)
            child = crossover(p1, p2)
            child = mutate(child)
            new_pop.append(child)
        population = new_pop
    return max(population, key=fitness_function)

best = genetic_algorithm()
print(f"Лучшее решение: {best}, значение функции: {fitness_function(best)}")
```

Что за алгоритм: Генетический алгоритм - эвристический метод оптимизации, имитирующий естественный отбор. Особи (решения) скрещиваются, мутируют, и выживают сильнейшие. Позволяет находить приближенные решения сложных задач.

Пример из жизни: Проектирование крыла самолета. У нас есть множество параметров (форма, угол наклона, материалы) и цель - минимизировать сопротивление воздуха. Пространство параметров огромно, точный перебор невозможен. Генетический алгоритм создает "популяцию" вариантов крыльев, скрещивает лучшие, добавляет случайные мутации, и через много поколений получает почти оптимальную форму.
